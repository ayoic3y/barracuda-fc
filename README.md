# ФК «Барракуда» (Минск) — сайт команды

Готовый статический сайт: HTML + CSS + JS без сборщиков и зависимостей.
Открывается двойным щелчком по `barracuda-fc/index.html` — сервер не нужен.

## Структура

```
barracuda-fc/              ← готовый сайт (это и есть результат сборки)
  index.html               главная: следующий матч с отсчётом, последние 5 матчей,
                           новости, «Мы в цифрах», гонка бомбардиров, таблица лиги
  matches.html             календарь / результаты / таблица лиги
  squad.html               состав (24 игрока) с фильтром по амплуа + бомбардиры
  news.html                лента новостей + отдельные статьи в news/
  club.html                «Мы в цифрах», история, домашняя площадка
  contacts.html            форма связи, где играем, соцсети, FAQ
  404.html                 страница ошибки
  css/style.css            дизайн-система (фиолетово-синяя тёмная тема, адаптив)
  js/main.js               меню, табы, фильтры, обратный отсчёт до матча, анимации
  assets/                  эмблема, favicon, фото игроков, обложки новостей
  sitemap.xml, robots.txt

_src/                      ← исходники сайта
  data.py                  ВСЕ тексты: клуб, состав, бомбардиры, матчи, таблица, новости
  generate.py              генератор страниц (шапка и подвал собираются из одного места)
  linkcheck.py             проверка ссылок и ключевых блоков: python _src/linkcheck.py
  style.css, main.js       исходники стилей и скриптов
  assets/                  logo.png, favicon, players/ (фото игроков), news/ (обложки новостей)

preview/                   скриншоты страниц (как сайт выглядит на ПК и на телефоне)
```

## Как обновлять сайт

1. Правите текст в `_src/data.py` (или кладёте фото в `_src/assets/...`).
2. Запускаете пересборку:

```powershell
python _src/generate.py
```

3. Смотрите `barracuda-fc/index.html`. Пересборка полностью пересобирает папку `barracuda-fc`.

### Частые операции

| Что нужно | Как |
| --- | --- |
| **Новая новость** | блок в начало списка `NEWS` (первая новость — крупной карточкой на главной). `slug` — латиницей, это имя файла статьи. Рубрику добавьте в `NEWS_CATS`. |
| **Фото к новости** | положите файл в `_src/assets/news/`, в новости укажите `"image": "news/имя-файла.jpg"` — фото встанет на обложку карточки и в статью. Пустое поле = градиент со словом `glyph`. |
| **Фото игрока** | положите снимок в `_src/assets/players/` с именем `p<номер>.jpg` (например `p21.jpg` — фото Радкевича уже стоит). |
| **Результат матча** | в `MATCHES` вместо `"score": None` впишите `[хозяева, гости]`. Матч сам уедет из «Календаря» в «Результаты», обновится форма последних 5 матчей. |
| **Новый матч** | строка в конец `MATCHES`, `"score": None`. «Следующий матч» и отсчёт считаются по дате автоматически. Соперник неизвестен — пишите `"неизвестно"`. |
| **Таблица лиги** | `STANDINGS`: `played, w (победы в осн. время), wp (по пенальти), dp (ничьи/пораж. по пен.), l, gf, ga, pts, form` (`form` — последние матчи слева направо: `w, wp, d, lp, l`). Процент набранных очков считается сам. |
| **Бомбардиры** | `SCORERS`: `goals` и `assists`, колонка «Всего» считается сама. |
| **Состав** | `SQUAD`: `num, name, pos, group (gk/df/mf/fw), born, height, foot, apps, goals, captain`. |
| **Мы в цифрах / Почему мы такие / история** | `CLUB_FACTS`, `CLUB_VALUES`, `TIMELINE` + текст `CLUB["intro"]`. |
| **Кнопка «Задонатить»** | `CLUB["donate_url"]` — вставьте ссылку на сбор (DonationAlerts, банк и т. п.), сейчас ведёт на страницу «Контакты». |
| **Цвета, шрифты, отступы** | `_src/style.css`, токены в `:root`. |

## Что стоит проверить/заменить на реальное

* навигация к 67 школе («метро Малиновка…») и формулировка про свободный вход — придуманы для заполнения страниц;
* тексты FAQ в `_src/data.py` (`FAQ`);
* ссылки на соцсети в `SOCIALS` — сейчас заглушки `#`;
* в составе, кроме Радкевича Даниила, пока остались демонстрационные имена — пришлите реальные (номер, амплуа, год, рост, матчи, голы);
* домен в `CLUB["site_url"]` (сейчас `barracuda-fc.ru`) — влияет на `sitemap.xml` и `robots.txt`.

## Публикация

Папка `barracuda-fc` — обычная статика: GitHub Pages, Netlify, Cloudflare Pages или любой хостинг.
Внутри уже есть `sitemap.xml`, `robots.txt` и `.nojekyll`.

* **Пересборка одной кнопкой:** двойной щелчок по `build.cmd` (сайт соберётся и откроется).
* **Выложить в интернет:** пошаговая инструкция — [HOSTING.md](HOSTING.md)
  (GitHub Pages с автодеплоем, Netlify/Cloudflare, обычный FTP).
* В проекте инициализирован git, есть `.gitignore` и настройка автопубликации
  `.github/workflows/pages.yml`: после подключения репозитория сайт пересобирается
  и публикуется сам при каждом `git push`.
